HybridEngine · Graph Capture · Accelerator Agnostic

Turning graph capture from CUDA-only
into a generic accelerator capability

Inference decoding in DeepSpeed HybridEngine is bound by CPU launch overhead, and graph capture compresses thousands of kernel launches into a single replay. But two fast paths were hardcoded for CUDA. This page walks through the root cause, the capture workflow, and the two fixes that actually get it running on Ascend NPU.

01 / Bottleneck

A decode step is bound by the CPU, not the device

Each autoregressive decode step adds a single token, yet launches thousands of small kernels. Every kernel on the device is short, so the device finishes and then waits for the CPU to queue the next one. Graph capture records the whole forward pass once, and every step afterwards is a single replay. Press play to compare two ways of running the same decode step.

04 / NPU challenges

Once gating is open, two operator-level issues remain

This is the part of the port that demands the deepest low-level debugging: one issue is a CANN restriction on capturing side streams, the other is a KV cache overflow caused by a process-wide counter.

Fused attention: v1/v2 → v3

v1/v2 launch work on an internal side stream, and CANN rejects the capture at capture_end (error 107025). v3 uses no side stream and captures cleanly in the BSH layout.

KV cache table grows on demand

layer_id comes from num_layers, a process-wide monotonically increasing counter. When a second engine is built in the same process, layer_id runs past the table length, so the table now appends on demand.

06 / Safety

Correctness first: no unsafe case slips through

All existing rejections are preserved and made device-agnostic; a capture failure at runtime falls back to eager rather than crashing the job or silently computing wrong results.

×

ZeRO stage 3

Parameters are gathered into a new buffer every step; replaying a stale graph silently computes the wrong result

×

release_inference_cache

After the workspace is released, the buffers the graph wrote into no longer exist

×

inference_tp_size > 1
