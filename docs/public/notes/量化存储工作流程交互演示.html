背景与概念

Context

LoRA 微调的显存结构

基座模型全部冻结、只有少量 adapter 训练。冻结参数不产生梯度，却仍占着绝大部分参数显存，是压缩收益最大的一块。

分组量化（grouped quantization）

把权重切成若干组，每组用自己的 absmax 算一个 scale，编码为 int8；反量化时按组乘回，误差控制在组内 1 个 LSB。

分区与合并桶

ZeRO-3 把参数切成 N 份分驻各 rank；fetch 时多个参数打包进一个 coalesced 桶，一次 all-gather 取回，再逐参数拆开。

下面两个交互模块分别演练「单个参数分区的完整生命周期」与「多参数合并桶的反量化过程」，所有数字都由页面内的固定数据实时计算。

验证证据与边界

Evidence

回归测试钉住问题

新增 test_quantized_nontrainable.py，world size 1 与 2 在 910B4 和 A100 均通过；同一测试在 master 上以「quantized storage is all zeros」失败。

量化契约与真实模型

量化器 242 个单测全过；Qwen3-0.6B/1.7B/4B LoRA 实测非零率 98.8%、冻结存储字节数减半、loss 正常收敛。

offload 语义与舍入

CPU 参数 offload 初始化直接拒绝，NVMe 跳过量化并警告；NPU 量化器补齐 int4/非对称，截断改 half-to-even 对齐 CUDA。
